# 河流声音地图 · 亲子互动装置

孩子沿着一条虚拟河流拖动声波碎片，把它们拼成一段会随水流变化的声音地图；家长调节河流速度与水位，孩子在不同水位下寻找被淹没的音符。

无需登录、无后端、无外部音频资源（全部声音由 Web Audio 实时合成）。

## 玩法

**孩子**
- 把河里漂着的声波碎片（do re mi sol la…）拖进顶部 6 个圆圈，拼出循环播放的河流之歌
- 把碎片从圆圈拖回河里即可取下；拖到已占用的圆圈会交换
- 水位上涨时，河床上的 ♪ 音符被淹没后会发光冒泡，点一下收集；集齐 6 个触发庆祝音阶并刷新一轮

**家长（右上角 🎛️ 面板）**
- 🌊 水流速度：同时影响碎片漂流速度、音序器 BPM、音色亮度和水声大小
- 💧 水位高低：决定哪些音符被淹没、可以被找到
- ☀️ / 🌧️ / 💨 三种天气：晴天波光、雨天涟漪+雨滴声、风天落叶+阵风推碎片（待机 75 秒自动轮换）
- 🎙️ 录一段声音：调用手机麦克风录 4 秒，孩子的声音会变成一块新的橙色碎片游进河里
- 📚 本地作品集：给孩子的河流之歌起名字保存；之后可随时重新打开、覆盖保存或另存为新歌、删除；单首可导出成备份文件，在另一台设备导入继续编辑
- 🔊 静音开关

## 作品集（本地保存）

家长在面板底部的「📚 河流之歌作品集」里：

- **💾 保存这首歌**：首次保存会弹窗让家长命名（留空则自动取名）；正在编辑某首歌时再点即覆盖保存，也可用「另存为新歌」存成新作品
- **重新打开**：点列表里任意作品，整条河流恢复成保存时的样子
- **📤 导出**：点作品旁的 📤 把这一首存成 `.river-song.json` 备份文件，可经微信 / AirDrop 发到另一台设备
- **📥 导入**：在另一台设备点「导入作品备份」选中该文件，歌就进作品集了（不会自动打开，点一下才恢复河流）；若与本机已有作品重复，会存成新作品、两者都保留
- **删除**：点 🗑️ 后需再点一次确认（3 秒不确认自动取消），防止误删孩子的作品

每首歌完整保存：**6 个格子的顺序与空格、河里所有声音碎片及孩子的录音、水流速度、水位、天气**。
数据只写在这台设备浏览器的 localStorage（键名 `river-songs-v1`），无后端、无登录、不上传；录音以 base64 存储，本地空间不足时会提示家长。导出的备份文件就是单首作品的存档 JSON（含 base64 录音），导入时复用与读取本地存档相同的逐字段校验，损坏或不是备份的文件会被明确拒绝。

## 技术栈

p5.js（渲染）· TypeScript · Vite · Web Audio API（合成 + 音序器 + 录音解码）· Matter.js（浮力/漂流/阵风物理）

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 打包到 dist/
npm run preview  # 预览构建产物
```

## 手机上调试麦克风

`getUserMedia` 要求安全上下文（HTTPS 或 localhost）：

- 电脑本机直接开 `http://localhost:5173` 即可
- 手机访问电脑局域网 IP 是 HTTP，麦克风会被浏览器拒绝。可以：
  - 用 `npx vite --host` 配合隧道（如 `ngrok http 5173`）获得 HTTPS 地址
  - 或部署到任意静态 HTTPS 托管（`npm run build` 后上传 `dist/`）

## 目录结构

```
src/
  main.ts            入口
  Game.ts            编排：物理力、拖拽、格子、音符、存档序列化/恢复、渲染
  audio/AudioEngine  音序器 + 水/雨/风环境声 + 音效（纯合成）
  audio/MicRecorder  麦克风录音入口
  data/Portfolio     本地作品集：localStorage 增删改查 + 录音 base64 编解码
  world/Fragment     声波碎片（Matter 刚体 + 波形绘制，带稳定 id）
  world/Notes        被淹没的音符与气泡
  world/Weather      晴/雨/风粒子系统
  ui/Panel           家长面板（HTML 覆盖层，含作品集列表与命名对话框）
```
